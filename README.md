#  Voice-Enabled AI Assistant Chatbot

A Streamlit-based voice and text chatbot that uses a trained ML model (SVM or Random Forest) to classify spoken commands, combined with NLTK-based text intent detection and Google Text-to-Speech responses.

---

## 📁 Project Structure

```
.
├── code_02_chatbot.py        # Main Streamlit app
├── training_chat_bot.py      # Model training pipeline
├── requirements.txt          # Python dependencies
├── best_model.joblib         # Saved best model (SVM or RF) — generated by training
├── label_encoder.joblib      # Saved label encoder — generated by training
├── dataset_cache.joblib      # Cached dataset + scaler — generated by training
├── static/                   # Auto-created; stores recorded input.wav and output.mp3
│   ├── input.wav
│   └── output.mp3
└── speech_commands_v0.02/    # Google Speech Commands dataset (must be downloaded)
    ├── yes/
    ├── no/
    ├── up/
    └── ...
```

## ⚙️ Setup & Installation

### 1. Clone / download the project

```bash
git clone https://github.com/mohamedbenothman-lab/speech_recognition_chat_bot
cd <project-folder>
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

> **Note:** On some systems you may also need to install `portaudio` for microphone access:
> - macOS: `brew install portaudio`
> - Ubuntu/Debian: `sudo apt-get install portaudio19-dev`

### 3. Download the Speech Commands dataset

Download the [Google Speech Commands v0.02 dataset](https://storage.googleapis.com/download.tensorflow.org/data/speech_commands_v0.02.tar.gz) and extract it into the project root:

```bash
mkdir speech_commands_v0.02
tar -xzf speech_commands_v0.02.tar.gz -C speech_commands_v0.02/
```

### 4. Enable Streamlit static file serving

Add the following to your `.streamlit/config.toml` (create the file if it doesn't exist):

```toml
[server]
enableStaticServing = true
```

## Training the Model

Run the training script **before** launching the app. This will:
- Extract MFCC + chroma + spectral contrast features from all audio files
- Apply data augmentation (time-stretch, pitch-shift, white noise)
- Balance classes via oversampling
- Train both an SVM and a Random Forest with 5-fold cross-validated GridSearchCV
- Save the best model to `best_model.joblib`

```bash
python training_chat_bot.py
```

Recognized command words: `yes`, `no`, `up`, `down`, `left`, `right`, `on`, `stop`

> The dataset and model are cached to disk after the first run, so subsequent runs are much faster.

## How It Works

### Voice Input (ML Model)
1. Click **🎤 Record** — the app listens via your microphone for up to 10 seconds.
2. The recorded audio is saved to `static/input.wav` and visualised (waveform + spectrogram).
3. Google Speech Recognition transcribes the audio to text.
4. The saved WAV is also passed through the trained ML model to classify the **intent** directly from audio features.
5. A TTS response is generated and played back.

### Text Input (NLTK)
1. Type a message in the chat input box.
2. A Context-Free Grammar (CFG) parser first checks for timer commands (e.g. *"set a five minute timer"*).
3. If no timer is detected, NLTK tokenizes and lemmatizes the text to match keywords to intents.

### Supported Intents

| Intent           | Example trigger           | Response                                  |
|------------------|---------------------------|-------------------------------------------|
| `get_weather`    | "weather"                 | Reports sunny forecast                    |
| `control_lights` | "light"                   | Confirms light control                    |
| `set_timer`      | "set a five minute timer" | Starts a timer                            |
| `tell_joke`      | "joke"                    | Tells a joke                              |
| `greet`          | anything else             | Greets the user                           |

## 🔧 Feature Extraction

Each audio sample is represented as a fixed-length vector combining:

| Feature              | Dimension     |
|----------------------|---------------|
| MFCCs                | n_mfcc × 2   |
| Delta-MFCCs          | n_mfcc × 2   |
| Delta²-MFCCs         | n_mfcc × 2   |
| Chroma               | 12 × 2       |
| Spectral Contrast    | 7 × 2        |
| Zero-Crossing Rate   | 1 × 2        |

Mean and standard deviation are both computed across time frames, giving a richer representation than mean alone.

## Notes

- A working **internet connection** is required for Google Speech Recognition (`speech_recognition`) and Google TTS (`gTTS`).
- The `static/` folder is created automatically on first run.
- NLTK data (`punkt`, `wordnet`) is downloaded automatically on startup.
- If no model files are found, run `training_chat_bot.py` first.
